2. Hordhaca Variable-yada (Variables)Waa maxay Variable? Waa meel loo sii qoondeeyay RAM-ka si loogu kaydiyo xogta inta uu barnaamijku socdo.   Sida loo bazeeyo (Syntax): DataType VariableName;   Shuruudaha Bayaaninta Magacyada (Naming Conventions):Xarafka ugu horeeya waa in uu noqdaa xaraf (A-Z) ama underscore (_).   Ma laha karama spces (Meel baxsan).   Ma adeegsan kartid Keywords ama magacyada loo dhigtay C#.   String Variables & ConcatenationString: Waa iskujira xaraf iyo nambaro.   Concatenation (+): Waa isku xirka laba string ama string iyo numeric value.   C#string fullName;
fullName = firstNameTextBox.Text + " " + lastNameTextBox.Text;
Local Variables & ScopeLocal Variable: Waa variable lagu bazeeyay gudihiisa method/event handler. Wuxuu jiraa oo kaliya inta uu method-kaasi socdo.   Scope: Waa qaybta uu barnaamijku ka aqoon karo varialbe-kaas.   3. Noocyada Xogta Nambaraadka ah (Numeric Data Types)C# waxay leedahay noocyo kala duwan oo nambaraad ah:   int: Nambaraad chih ah (Whole numbers, e.g., -2,147,483,648 ilaa 2,147,483,647).   double: Nambaraad jajab leh (Real numbers with decimal points).   decimal: Nambaraad precision sare leh oo badanaaba loo adeegsado dhaqaalaha ama lacagta (Financial applications). Waxaa la raaciyaa m ama M marka loo assign gareynayo literal value.   Explicit Conversion (Type Casting)Hadii aad rabtid inaad xog ka bedesho nooc oo aad u bedesho nooc kale:   C#decimal moneyNumber = 4500m;
int wholeNumber = (int)moneyNumber; // Casting decimal to int
Var KeywordWaxaad adeegsan kartaa var si uu compiler-ku isaga garto data type-ka nooca uu yahay:   C#var interestRate = 12.0; // Double
var stockCode = "D465U"; // String

Maareynta Qaladaadka (Simple Exception Handling)Exception: Waa qalad dhaca inta barnaamijku socdo (Runtime error) oo keeni kara in barnaamijku iska xirmo (Crash).   Try-Catch Statement: Waxaa loo adeegsadaa in lagu qabto (catch) qaladka si barnaamijku uusan u istaagin.   C#try
{
    double miles = double.Parse(milesTextBox.Text);
    double gallons = double.Parse(gallonsTextBox.Text);
    double mpg = miles / gallons;
    mpgLabel.Text = mpg.ToString("F1");
}
catch (Exception ex)
{
    MessageBox.Show(ex.Message); // Wuxuu soo qaadayaa qoraalka qaladka
}
8. Adeegsiga Constant-yada Magaca leh (Named Constants)Waa variable aan xogtiisu bedelmi karin inta barnaamijku socdo. Waxaa la isticmaalaa keyword-ka const:   C#const double INTEREST_RATE = 0.129;
9. Bayaaninta Variable-yada Sida Fields (Field Variables)Field: Waa variable lagu dhex bayaanay Class-ka gudihiisa, balse aan ku dhex jirin Method hoosaad.   Waxaa laga wada isticmaali karaa dhamaan Method-yada ku jira Class-kaas (Form-kaas).   C#public partial class Form1 : Form
{
    private string name = "Charles"; // Field Variable
    
    private void showNameButton_Click(object sender, EventArgs e)
    {
        MessageBox.Show(name);
    }
}
10. Adeegsiga Math ClassSystem-ka .NET wuxuu bixiyaa Math class oo lagu sameeyo xisaabaadka adag:   Math.Sqrt(x) - Isku dhul-kudhayga nambarka (Square root).   Math.Pow(x, y) - Power ($x^y$).   Math.Max(x, y) & Math.Min(x, y) - Ka ugu weyn ama ugu yar.   Math.Round(x) - Isku duubidda nambarka.   Constants Pre-defined ah: Math.PI iyo Math.E.   11.
